# example-badge — the repo demonstrating its own output

A rounded badge with a raised "3D" wordmark, generated by a committed
script and run through the full pipeline on the machine that owns this
repo. The quality report alongside is the real output of that run:
verdict `print-ready`, meaning the level-2 headless OrcaSlicer slice ran
and passed both gates.

## Regenerate from scratch

```
uv run python scripts/make_example_image.py <somewhere>\example-badge-source.png
uv run make3d <somewhere>\example-badge-source.png --type keychain --name example-badge
```

The generator is deterministic (no randomness, no timestamps) **given
this machine's fonts**: it tries Impact / Arial Bold / Verdana Bold and
falls back to hand-drawn block letters when none exist. On a machine
with one of those fonts, the traced geometry and every check
measurement reproduce exactly. On a font-less machine (typical
Linux/macOS) the fallback letters shift a few measured values (face
counts, detail area, estimated print time) while the verdict and every
pass/fail still match — judge staleness by verdict and passed flags in
that case, not measured values.

Note: `make3d` rebuilds this folder wholesale, which removes this
README — restore it from git (`git restore designs/example-badge/README.md`,
once this folder is committed) after regenerating.

## Re-verify (prove the committed report is not stale)

Run the pipeline a second time into a scratch root and diff the two
reports, ignoring only the volatile field:

```
uv run make3d <same png> --type keychain --name example-badge --designs-root <scratch>
```

Compare `report.json` files with `slicer.elapsed_s` excluded: the
verdict and every check's name/passed/measured must match (measured
values assume this machine's fonts — see above). The `.3mf` is not
byte-stable across runs (the 3MF spec's production extension embeds
random `p:UUID` values); its model geometry is identical once those are
normalized, so hash-compare `report.json`, `traced.svg`, and the STL
instead.

## Files

Committed: this README, `example-badge-source.png` (source copy),
`traced.svg`, `example-badge.3mf` (two named objects: base + detail, for
AMS two-color), `example-badge.stl` (single fused body), `report.md`,
`report.json`. Untracked regenerables (gitignored): the sliced
`*.gcode.3mf` and OrcaSlicer's `00000.log`.
